# R1.4 — AI crawler policy and llms.txt structure

## Goal

Replace the two-rule `robots.ts` with an explicit allow/deny roster for named search and AI agents, extend `llms.txt` to cover Malay and Chinese and the four missing English routes, and add a new `llms-full.txt` route that renders the same verified facts `chat-knowledge.ts` uses, in all three languages, from the content constants. Copy text stays placeholder-neutral; Release 3 refreshes the wording.

## Model and role

Sonnet, single technical executor. No reviewer pass.

## Inputs — read these first, in full

- `docs/superpowers/specs/2026-09-03-site-quality-programme-design.md` (section R1.4)
- `src/app/robots.ts` (15 lines)
- `src/app/llms.txt/route.ts` (45 lines)
- `src/lib/chat-knowledge.ts` (66 lines — the 31 fact bullets live in the `facts` template literal, lines 26–59)
- `src/lib/locale-routes.ts` (82 lines — `EN_ROUTES` and `LOCALE_PAIRS`)
- `src/lib/content.ts` — the exported constants `chat-knowledge.ts` imports at lines 1–14
- `src/lib/content-ms.ts` and `src/lib/content-zh.ts` — exported constants
- `scripts/release-audit.mjs` (its route walk over `.next/server/app`)

## Constraints

- **Facts never change.** Every fact string in `llms-full.txt` is interpolated from `content.ts`, `content-ms.ts` or `content-zh.ts`. Never retype a number, a fee, a date, a CMI phrase or an HRD Corp condition.
- **Banned patterns** in `scripts/content-clarity-audit.mjs` apply. `llms.txt/route.ts` sits under `src/app/**` so it is already scanned; the new `llms-full.txt/route.ts` will be scanned too.
- **Branch and release action.** Create `feat/r1-4-crawler-policy` from `codex/hostinger-deployment`. Pushing your feature branch to GitHub for CI is allowed and encouraged. Merging into `codex/hostinger-deployment` and pushing that branch **is the deployment**; it happens only after the full section-6 gate is green. Never do that from this brief.
- Hostinger configuration is out of scope for the whole programme.
- **Map correction:** `EN_ROUTES` has **37** entries, not 36, and there are **five** insight articles, not four. Derive route lists programmatically from `EN_ROUTES` / `LOCALE_PAIRS`; never hand-copy a route list.
- `src/app/manifest.ts` is unchanged. Do not touch it.
- Both routes must keep `export const dynamic = "force-static"`.

## Steps

2. **robots.ts — write the test first.** Create `src/app/__tests__/robots.test.ts` (or `src/lib/__tests__/robots.test.ts`; keep it under a directory vitest already includes, i.e. `src/**/*.test.ts`). Import the default export from `@/app/robots` and assert:
   - Every one of these agents has a rule with `allow: "/"` and `disallow` containing `"/api/"`: `*`, `Googlebot`, `Bingbot`, `OAI-SearchBot`, `ChatGPT-User`, `ClaudeBot`, `Claude-SearchBot`, `Claude-User`, `PerplexityBot`, `Perplexity-User`, `Google-Extended`, `Applebot`, `DuckAssistBot`.

   - `sitemap` ends with `/sitemap.xml` and `host` equals `SITE.url`.
3. `npm test` — the robots test fails. Rewrite `src/app/robots.ts` so it passes: build the `rules` array from two local constants `ALLOWED_AGENTS` and `BLOCKED_AGENTS`, mapping each to its rule object, keeping the `*` rule first. Keep the existing comment about search inclusion and training access being separate business choices. Re-run `npm test` — green.
4. **llms.txt route coverage — write the test first.** Add `src/app/__tests__/llms.test.ts` asserting, against the body returned by `GET()` from `@/app/llms.txt/route`:
   - For every path `p` in `EN_ROUTES` that is a **public, indexable** route, the body contains `${SITE.url}${p}` for the English entry and the `zh` and `ms` members of the matching `LOCALE_PAIRS` entry. Exclude the noindex routes: `/corporate-training`, `/online-executive-mba`, `/programmes/shift-hr`, `/lp/google`, `/lp/meta`, `/unsubscribed`. Define that exclusion list once in the test as `NOINDEX_ROUTES` and assert those URLs are **absent**.
   - The body still contains the four headings `# `, `## Primary sources`, `## Important interpretation`, `## Contact`.
5. `npm test` — the llms test fails (today's file lists nine English links and one `/zh` link). Rewrite `src/app/llms.txt/route.ts`:
   - Import `EN_ROUTES` (export it from `src/lib/locale-routes.ts` if it is not already exported — add `export` to the `const EN_ROUTES` declaration at line 7) and `LOCALE_PAIRS`.
   - Keep the existing English "Primary sources" block and its human-written one-line descriptions verbatim, then append entries for `/insights`, `/resources`, `/apply` and `/diagnostic` with equally terse descriptions.
   - Add two new sections, `## Malay sources (Bahasa Melayu)` and `## Chinese sources (简体中文)`, each generated by mapping the same indexable route list through `LOCALE_PAIRS` so the `/ms` and `/zh` mirrors are listed. Descriptions in these two sections stay in English and placeholder-neutral for Release 1 — one short clause naming what the page covers. R3.4 replaces them with final copy.
   - Leave `## Important interpretation` and `## Contact` untouched.
6. `npm test` — green.
7. **llms-full.txt — write the test first.** Add assertions to `src/app/__tests__/llms.test.ts` against `GET()` from `@/app/llms-full.txt/route`:
   - The body contains `FACTS.priceStd`, `FACTS.durationMonths`, `FACTS.trainingDays`, `FACTS.liveSessions`, `FACTS.moduleCount` and `FACTS.scholarshipProvider` as interpolated values (assert on the constant, not a literal).
   - The body contains `PROGRAMME_POSITIONING_SENTENCE`, `PROGRAMME_POSITIONING_MS` and `PROGRAMME_POSITIONING_ZH`.
   - The body contains `HRD_CORP_CLAIM.short`, `HRD_CORP_CLAIM_MS` and `HRD_CORP_CLAIM_ZH`.
   - The body contains three language section markers: `## English`, `## Bahasa Melayu`, `## 简体中文`.
   - Every one of the five `INTAKES` cohort ids appears.
8. **Share one fact source.** Refactor `src/lib/chat-knowledge.ts`: extract the `facts` template literal (currently built inline at lines 26–59) into an exported function `export function verifiedProgrammeFacts(language: ChatLanguage): string`. For Release 1 it may return the existing English body for every language — the point is that one function now owns the fact text. `programmeChatSystemPrompt` calls it. Run `npm test` to confirm nothing regressed.
9. Create `src/app/llms-full.txt/route.ts` with `export const dynamic = "force-static"` and a `GET()` that returns `text/plain; charset=utf-8` with the same `Cache-Control` header as `llms.txt`. Its body has a short header, then `## English` / `## Bahasa Melayu` / `## 简体中文` sections. The English section calls `verifiedProgrammeFacts("en")`. The Malay and Chinese sections interpolate the corresponding constants from `content-ms.ts` and `content-zh.ts` plus the shared numeric facts from `content.ts`. Every value is an interpolation; there are no hand-typed facts.
10. `npm test` — green.
11. **Route check.** Run `npm run build`, then confirm `.next/server/app` contains built output for `robots.txt`, `llms.txt` and `llms-full.txt`. Run `npm run audit:release` and confirm the three routes are reached without failures. If the audit's `.html`-only walk skips them (it filters on `extname === ".html"`), note that in the hand-back and additionally verify by `curl -s http://localhost:3000/llms-full.txt | head -20` against `npm start`.
12. Run the full gate (see Acceptance). Commit as three commits: robots, llms.txt, llms-full.txt — each with its test in the same commit.
