# Bundled fonts (OFL)

All families below are SIL Open Font License 1.1 (`OFL.txt` in this directory, identical text for all three families as published upstream).

- **Noto Sans** — Version 2.003 — `NotoSans-Regular.ttf`, `NotoSans-Bold.ttf` — static hinted instances from https://github.com/notofonts/NotoSans/tree/main/fonts/ttf/hinted/instance_ttf (license: https://github.com/notofonts/NotoSans/blob/main/LICENSE)
- **Noto Serif** — Version 2.003 — `NotoSerif-Regular.ttf`, `NotoSerif-Bold.ttf` — static hinted instances from https://github.com/notofonts/NotoSerif/tree/main/fonts/ttf/hinted/instance_ttf (license: https://github.com/notofonts/NotoSerif/blob/main/LICENSE)
- **Noto Sans SC** — Version 2.004 — `NotoSansSC-Regular.ttf`, `NotoSansSC-Bold.ttf` — derived from the official variable font https://github.com/notofonts/noto-cjk/blob/main/Sans/Variable/TTF/Subset/NotoSansSC-VF.ttf (a mirror of upstream `google/fonts` / `googlefonts/noto-cjk`), instanced to static `wght=400` and `wght=700` TrueType outlines with `fonttools` 4.64.0 (`python -m fontTools.varLib.instancer -o NotoSansSC-Regular.ttf NotoSansSC-VF.ttf wght=400`, and `wght=700` for Bold), then the source variable file discarded. This step was necessary because ReportLab's `TTFont` cannot embed PostScript/CFF outlines (the only static Regular/Bold files Google publishes for Noto Sans SC are `.otf` CFF, under `Sans/SubsetOTF/SC/` in the same repo) and cannot select a named instance out of a variable font at render time, so a plain static TrueType instance was required. License: https://github.com/notofonts/noto-cjk/blob/main/LICENSE (same OFL 1.1 text).
